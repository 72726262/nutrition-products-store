# متجر منتجات التغذية والمكملات الصحية 🥗💪

موقع ويب حديث واحترافي لبيع منتجات التغذية والمكملات الرياضية والصحية، مصمم ومبني بأحدث تقنيات الويب مع دعم كامل للغة العربية.

---

## ✨ المميزات المتاحة في المتجر

- 🎨 **تصميم عصري وجذاب**: واجهة مستخدم بألوان متناسقة وتدرجات ناعمة مع خطوط عربية حديثة (Tajawal & Cairo).
- 🛒 **سلة تسوق تفاعلية متكاملة (Cart Drawer)**:
  - فتح وإغلاق سلس لسلة المشتريات.
  - إمكانية زيادة (+) أو تقليل (-) الكميات لكل منتج.
  - حذف منتجات فردية أو تفريغ السلة كاملة.
  - حساب فوري وديناميكي لإجمالي السعر.
  - حفظ محتويات السلة في `localStorage` لعدم فقدانها عند تحديث الصفحة.
- 🔍 **بحث فوري وفلترة متقدمة**:
  - شريط بحث سريع بالاسم أو الوصف.
  - تصفية حسب الفئات (بروتينات، فيتامينات، طاقة وأداء رياضي، منتجات عضوية).
- 📦 **نافذة تأكيد الطلب (Checkout Modal)**: نموذج بسيط لتسجيل بيانات العميل (الاسم، الجوال، العنوان) والدفع عند الاستلام.
- 🔔 **نظام إشعارات Toast حديثة**: تنبيهات تفاعلية أنيقة عند إضافة أو حذف أي منتج أو إتمام الطلب.
- 📱 **متجاوب 100% (Responsive)**: متوافق مع كافة الشاشات وأجهزة الجوال والأجهزة اللوحية.

## 🛠️ أوامر التشغيل والبناء (Build & Run)

```bash
# تثبيت الحزم
npm install

# تشغيل خادم التطوير المحلي
npm run dev

# بناء النسخة الإنتاجية (Production Build)
npm run build

# معاينة البناء
npm run preview
```

## ☁️ الربط والنشر على Cloudflare Pages

### الطريقة الأولى: عبر لوحة تحكم Cloudflare (موصى بها)
1. افتح [Cloudflare Dashboard](https://dash.cloudflare.com/).
2. انتقل إلى **Workers & Pages** > **Create application** > **Pages** > **Connect to Git**.
3. اختر مستودع المشروع: `nutrition-products-store`.
4. اضبط إعدادات البناء:
   - **Framework preset**: `Vite`
   - **Build command**: `npm run build`
   - **Build output directory**: `dist`
5. اضغط **Save and Deploy** وستحصل فوراً على رابط مباشر ودائم للموقع مع شهادة SSL مجانية: `https://nutrition-products-store.pages.dev`.

### الطريقة الثانية: عبر سطر الأوامر (Wrangler CLI)
```bash
# تسجيل الدخول لحساب Cloudflare
npx wrangler login

# رفع مجلد البناء مباشرة
npm run deploy
```
