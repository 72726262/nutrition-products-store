# متجر منتجات التغذية 🥗

موقع ويب حديث لبيع منتجات التغذية والمكملات الغذائية

## المميزات
- 🎨 تصميم حديث وجميل
- 📱 متجاوب مع جميع الأجهزة
- 🛒 سلة تسوق وظيفية
- 🌍 دعم اللغة العربية
- ⚡ أداء سريع وفعّال

## المنتجات
- بروتين الواي
- فيتامينات متعددة
- BCAA
- زيت السمك - أوميغا 3
- الكرياتين مونوهيدرات
- الجلوتامين
- مسحوق الكاكاو العضوي
- شاي أخضر عضوي

## البدء
1. افتح ملف `index.html` في متصفحك
2. استكشف المنتجات
3. أضف المنتجات للسلة

## التكنولوجيا
- HTML5
- CSS3
- JavaScript (Vanilla)
